§1 The anchor

A state is a set of element records, one per file — mode, path, and the SHA3-256 of the file's bytes, welded into one canonical line:

modepathsha3-256(blob)
anchor · fold of the three records

Two layers of hashing. The blob hash names the content; what feeds the sum is the hash of the record line itself:

sha3(main.rs bytes)  = ← names the content, lives inside the record
sha3(record line)   = ← this is the atom the arithmetic adds

Rename, chmod, or change one byte, and the old record leaves the set whole and a new record enters whole. There is no partial membership.

§2 Two agents fork the anchor

Each patch carries an intent (the precondition-bearing edit) and a realized delta (its record-level effect). Only the realized delta enters the arithmetic — old_str and new_str are never hashed into anything.

Agent A · edit /src/main.rs
digest(A) = −old record + new record
Agent B · create /src/lib.rs, edit /README.md
create /src/lib.rs edit /README.md old_str: "A tiny demo service.\n" new_str: "A tiny demo service.\n\nSee src/lib.rs for the API.\n"
preconditions: path absent ✓ · old_str unique ✓
digest(B)

§3 The prediction

Neither agent has seen the other's work. No merge exists. Three columnwise additions commit to what the merged state must sum to:

 anchor
+digest(A)
+digest(B)
predicted union — written down before the work commitment · made in advance

§6 When they don't align

Suppose replica 2's disk quietly flips version = "0.1.0" to "0.1.1" in Cargo.toml.

healthy  =
corrupt  =
healthy − corrupt =
digest(good Cargo.toml − bad Cargo.toml) =

The difference between two states is itself a patch digest — a checksum of exactly what diverged. Repair is targeted, not forensic.

§7 The negative half

Every sum so far described a state you could ls. The arithmetic is roomier than that. A "negative file" sounds like nonsense until you remember that negative numbers were invented for exactly this: there is no pile of −3 apples — −3 means I owe you three apples. Negative numbers describe transactions, not piles. A sum with negative parts describes an obligation, not a directory: take this exact record away from me. States are the nouns; the group also holds the verbs.

Every state carries its own anti-state.

anchor      =
anti-anchor =
anchor + anti-anchor =
annihilation · the checksum of the empty set

Sixty-four zeros is not "no checksum" — it is the checksum of nothing, and every state annihilates to it against its own negation. The anti-anchor is the "delete everything" patch, implicit in the anchor's own sum all along.

Undo is a sign flip. Negate digest(A) and you hold the reverting patch — not a description of reversal, the patch itself, as arithmetic:

 digest(A) =
−digest(A) =
(S₀ + A) + (−digest(A)) =

The −old main.rs inside digest(A) met the +old main.rs inside the anchor and annihilated it; the minus sign runs that in reverse. §6's healthy − corrupt was this same move wearing work clothes: a repair ticket is a sum with negative parts.

Debt can dangle. The arithmetic is free: subtract a record that isn't present, and nothing errors. Subtract the lib.rs record from the anchor — which doesn't contain it:

anchor − lib.rs record =
…then + lib.rs record =

No repository folds to the first value — it describes a state containing −1 copies of a file. The anti-record lingers as unsettled debt until a matching insert cancels it. This freedom is what makes patches portable and order-blind, and it is why the arithmetic alone can't keep states real. Hence the spec's soundness rule: the sum attests; the manifest adjudicates. Arithmetic keeps the books; the manifest checks that the debtor exists.
